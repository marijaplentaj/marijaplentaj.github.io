# Marija Plentaj – GitHub Pages

## Datoteke
- `index.html` – sadržaj weba
- `style.css` – izgled
- `images/harmonika.jpg` – zamijeni svojom fotografijom

## Kako dodati PDF
U `index.html` pronađi:
`href="#"`

i umjesto `#` zalijepi javni link na PDF s Google Drivea.

## Kako promijeniti fotografiju
Stavi svoju fotografiju u folder `images` i nazovi je:
`harmonika.jpg`

Ako koristiš drugo ime datoteke, promijeni ga i u `index.html`.

## Objavljivanje
Repozitorij na GitHubu nazovi:
`tvojusername.github.io`

Zatim:
Settings → Pages → Deploy from a branch → main.
